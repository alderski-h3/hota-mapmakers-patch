# Changelog

## 1.0.0-beta.8 — 2026-11-07

- Redesigned the native launcher with new artwork, clearer update status and a compact changelog.
- Install updates without a second confirmation. Launch focuses an editor already running from the same installation instead of opening another copy.
- Restore the verified previous patch and launcher together. A separate local recovery entry remains available if the launcher cannot start.
- Update files and backups now use a dedicated `HotA Mapmakers Patch` folder.
- Advanced Find excludes chance-only artifact containers. Guaranteed artifacts remain searchable; creature banks with an unspecified variant still show their possible artifact classes.

## 1.0.0-beta.7 — 2026-11-06

- Advanced Find can show or exclude random spells and artifacts. Random bank rewards show possible artifact tiers; spell searches include guaranteed Mage Guild spells.
- Added Object reinforcements for Ancient Lamps, Trapper Lodges and Refugee Camps. Creatures can also be found in supported extended-event combats.
- Fixed Seer’s Hut bonus rewards, quests targeting random monsters, and stale results after dragging objects off the map. Bonus amounts sort numerically, and inactive standard rewards no longer appear for boxes or events using an extended event.
- The launcher closes after starting the patched editor.

## 1.0.0-beta.6 — 2026-11-05

- Advanced Find: search for primary skills, experience, movement points, spell points, morale and luck from map objects and rewards.
- The ZIP includes a one-click patched editor shortcut EXE. Starting the editor from the patch launcher leaves its update status visible.

## 1.0.0-beta.5 — 2026-11-05

- HotA Mapmaker’s Patch: updated name, filenames and presentation.
- Patch and launcher updates are available from this repository.
